# Flight Fare Prediction using Machine Learning

## Overview
This project predicts airline ticket prices using regression-based machine learning algorithms.

## Features Used
- Airline
- Source
- Destination
- Duration
- Total Stops
- Departure Time
- Arrival Time

## Algorithms Used
- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor

## Technologies
- Python
- Pandas
- Scikit-learn
- Matplotlib
- Seaborn

## Results
Random Forest Regressor achieved the best prediction performance.
